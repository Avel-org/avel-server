- **Better Auth stamps its own times.** Its tables have snake_case columns, uuid ids from the injected `IdGenerator`, and no database defaults, but `created_at`, `updated_at` and `expires_at` come from Better Auth's clock, not the injected `Clock` (`src/auth/index.ts`). - **The first-mission test found two gaps** (`tests/api/first-mission.test.ts`, 2026-10-21): no route created an agent template, so the test inserted one; and nothing checked that the repository an intake read is the one the room opens (there a client repository was read and the template opened).
